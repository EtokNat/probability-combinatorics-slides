# Probability via Enumeration & Combinatorics

Web-based Reveal.js presentation for Cambridge AS Level Mathematics (9709), Topic 3.1.

- **Open the live slides:** https://etoknat.github.io/probability-combinatorics-slides/
- **Navigate:** → / ↓ advance, ← / ↑ go back, `F` for fullscreen, `S` for speaker notes, `ESC` for overview.
- **Math:** rendered via MathJax 3.
- **Theme:** custom dark classroom theme, Fraunces + Inter + JetBrains Mono.
- **Duration:** 70 minutes · 10 slides with fragment-by-fragment reveals.
